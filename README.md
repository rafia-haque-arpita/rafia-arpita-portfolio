# Rafia Haque Arpita — Portfolio

Next.js (App Router) + TypeScript. Dark "Neon Noir Violet" theme.

All text lives in `src/content/site.ts`. Edit that one file to change copy.

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Production
```bash
npm run build
npm start
```

## Deploy
Push to GitHub, then import the repo at https://vercel.com/new and click Deploy.
